# Security policy

## Supported versions

Security fixes are applied to the latest published release.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** private reporting flow for this repository. Do not open a public issue containing credentials, private media paths, or exploit details.

Cut IQ is designed to bind its HTTP server and bundled database to `127.0.0.1`. Reports involving unexpected network exposure, unsafe filesystem access, archive extraction, command execution, or project deletion boundaries are especially welcome.
